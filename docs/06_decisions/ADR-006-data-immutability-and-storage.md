# ADR-006: `data/raw` is immutable, stored in plain git with a checksum manifest

- Status: Accepted (2026-10-28, PI)
- Decision: Raw data (~64 MB at start; largest file 46.8 MB, under GitHub's 50 MB warning) are committed in plain git,
  byte-exact (`.gitattributes`: no EOL conversion under `data/`). `data/raw/MANIFEST.csv` records size, SHA-256,
  coverage, origin and caveats; `tests/test_data_manifest.py` verifies it. New or refreshed data go into new subfolders,
  never overwriting. Derived data go into `data/interim/` (git-ignored) and are regenerated by code.
- Consequences: If raw data grow past ~100 MB per file or ~1 GB total, revisit with Git LFS or external storage plus
  checksums (new ADR).
