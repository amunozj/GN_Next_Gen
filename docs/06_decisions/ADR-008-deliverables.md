# ADR-008: Deliverables

- Status: Accepted (2026-10-28, PI)
- Decision: (1) A full group-number series, 1610–present, released as a **posterior ensemble** (daily latent draws
  aggregated to monthly/yearly, with summary statistics) that competes with existing GN series; (2) an accompanying
  **methods paper**. The Maunder Minimum is **not the focus** but must be calibrated too, with honest prior-sensitivity
  and contraction diagnostics. Both variants of ADR-002 are released.
- Consequences: Every step's deliverables should feed either the series pipeline or a paper figure/table; the roadmap
  README keeps a running list of paper items.
