Rules (also in `CLAUDE.md` and ADR-006):
- `data/raw/` is immutable. New raw data go into new subfolders with a `MANIFEST.csv` row; `tests/test_data_manifest.py`
  checks every listed checksum.
- Derived data go into `data/interim/` (git-ignored except `.gitkeep`) and are regenerated by code in `src/`.
- Keep raw files byte-exact (`.gitattributes` disables EOL conversion under `data/`).
