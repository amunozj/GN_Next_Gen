## The KMAS single-use rule

KMAS appears **twice** in `data/raw`: as a reference survey in `reference_groups_2026-10/` and as an
observer-count source in `gn_observer_extension_2026-10/`. Its counts are derivable from its areas,
so using both puts the same observations into the likelihood twice and makes the posterior
overconfident.

> **Any run must declare KMAS's role as either reference areas or observer counts, never both.**

SWPC carries no such constraint: its areas are not in the reference. Enforcing this in the run
configuration is a Step 1 follow-up; until then the rule is documented here, in the extension's
README, and carried in the extension's `role` column. See ADR-009.
